# VSOL Router App

Android app (Kotlin, Jetpack Compose) for managing VSOL V2802DAC ONU/routers through their web admin interface.

- Package: `com.zyrotech.vsolrouter`
- Current version: 0.6.2

## Build

```
./gradlew assembleDebug
```

The Gradle wrapper jar/scripts are not included yet; generate them with `gradle wrapper` or open the project in Android Studio.
